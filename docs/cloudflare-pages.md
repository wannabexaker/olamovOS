# Cloudflare Pages

Use these settings for Olamov OS on Cloudflare Pages:

- Framework preset: None
- Build command: `yarn build:cloudflare`
- Build output directory: `out`
- Root directory: `/`
- Node.js version: `22`
- Package manager: Yarn Classic `1.22.22`

The repo pins Yarn through `packageManager` in `package.json`. This prevents Cloudflare from running Yarn 4 and failing on the `Burn-My-Windows` git dependency.

`wrangler.toml` sets `pages_build_output_dir = "./out"` so Pages can deploy the static export generated by Next.js.
