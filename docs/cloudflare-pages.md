# Cloudflare Pages

Use these settings for Olamov OS on Cloudflare Pages:

- Framework preset: None
- Build command: `yarn build:cloudflare`
- Build output directory: `out`
- Root directory: `/`
- Node.js: set `NODE_VERSION=22` (Environment variables)
- Yarn: set `YARN_VERSION=1.22.22` (Environment variables)

Notes:

- In the current Cloudflare Pages UI, there is usually no separate "Package manager" dropdown.
- Cloudflare installs dependencies automatically based on your repo and lockfiles.
- `package.json` also pins Yarn through `packageManager`, which helps prevent Cloudflare from using Yarn 4 on this project.

If you still see Yarn 4 in build logs, clear the Pages build cache and redeploy the latest commit on `main`.

`wrangler.toml` sets `pages_build_output_dir = "./out"` so Pages can deploy the static export generated by Next.js.

## Build fixes

### OpenSSL legacy provider (browserfs postinstall)

Node 22 ships OpenSSL 3.x which removed the MD4 hash used by webpack 4 inside `browserfs`. The `preinstall` script in `package.json` writes `node-options=--openssl-legacy-provider` to `~/.npmrc` before dependencies are installed, so the flag is active when browserfs's `postinstall` runs `npm run dist`.

### Cloudflare Pages 25 MB file-size limit

Cloudflare Pages rejects any single file larger than 25 MB. The `build:cloudflare` script deletes oversized files from `out/` after the Next.js export finishes (`find out -type f -size +25M -delete`). Affected files:

- `Program Files/BoxedWine/fullWine1.7.55-v8.zip` (47.7 MB)
- `Program Files/Quake3/Quake3Game.pk3` (38 MB)
- `System/ffmpeg/ffmpeg-core.wasm` (30.7 MB)

These apps will not work on the Cloudflare deployment. To restore them, host the large assets externally (R2, S3, etc.) and update the app code to fetch from there.
