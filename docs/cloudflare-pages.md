# Cloudflare Pages

Use these settings for Olamov OS on Cloudflare Pages:

- Framework preset: None
- Build command: `yarn build:cloudflare`
- Build output directory: `out`
- Root directory: `/`
- Node.js: set `NODE_VERSION=22` (Environment variables)
- Yarn: set `YARN_VERSION=1.22.22` (Environment variables)

Notes:

- In the current Cloudflare Pages UI, there is usually no separate "Package manager" dropdown.
- Cloudflare installs dependencies automatically based on your repo and lockfiles.
- `package.json` also pins Yarn through `packageManager`, which helps prevent Cloudflare from using Yarn 4 on this project.

If you still see Yarn 4 in build logs, clear the Pages build cache and redeploy the latest commit on `main`.

`wrangler.toml` sets `pages_build_output_dir = "./out"` so Pages can deploy the static export generated by Next.js.
